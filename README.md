# 📲 Missed Call Text Back AI

An AI-powered missed call recovery system built to help businesses automatically engage missed callers, qualify leads, and improve customer response times.

---

# 🚀 Overview

Many local businesses miss calls while serving customers, costing them potential revenue.

This project automatically detects missed calls, sends an AI-powered SMS response, qualifies the lead through conversation, and stores customer information for follow-up.

---

# ✨ Features

- 📞 Detects missed calls instantly
- 🤖 AI-powered SMS conversations
- 🧠 Lead qualification
- 📅 Appointment booking support
- 📊 Google Sheets CRM integration
- 🔔 Business owner notifications
- ⚡ Fully automated workflow
